# Overview and contacts

The supplied handbooks cover undergraduate international admission for Spring 2027 and Fall 2027. Spring is the March intake; Fall is the September intake. The graduate timeline page labels these intakes March and September.
The handbooks state that the Korean version is the official regulated application guide when language versions conflict; English and Chinese versions are for convenience.
